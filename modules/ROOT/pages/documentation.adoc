== User Guide
The xref:userguide::index.adoc[User Guide] is the reference documentation for Tapestry, versioned alongside the framework.
Use the version selector to switch between releases.

Two companion sections sit next to it in the same navigation: a *Cookbook* of worked recipes (including the xref:userguide:cookbook:ioc-cookbook.adoc[IoC Cookbook]) and the *FAQ*.

== Getting Started
